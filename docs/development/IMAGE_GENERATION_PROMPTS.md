## 🔑 GOOGLE MAPS API SETUP (Required for Bakery Demo)

**What You Need:** Google Maps Embed API (FREE - 28,000 map loads/month)

### **Step-by-Step Instructions:**

1. **Go to Google Cloud Console:**
   - Visit: https://console.cloud.google.com/

2. **Create a New Project (or use existing):**
   - Click "Select a project" dropdown at top
   - Click "New Project"
   - Name: "Moonlit Studios Demos"
   - Click "Create"

3. **Enable Google Maps Embed API:**
   - In the search bar, type "Maps Embed API"
   - Click "Maps Embed API"
   - Click "Enable"

4. **Create API Key:**
   - Go to "Credentials" (left sidebar)
   - Click "Create Credentials" → "API Key"
   - Copy your API key (it will look like: `AIzaSyBXXXXXXXXXXXXXXXXXXXXXXXXX`)

5. **Restrict API Key (IMPORTANT for security):**
   - Click "Edit API key" (pencil icon)
   - Under "API restrictions":
     - Select "Restrict key"
     - Check "Maps Embed API"
   - Under "Website restrictions":
     - Add: `moonlstudios.com/*`
     - Add: `*.vercel.app/*` (for dev/preview deployments)
     - Add: `localhost:3000` (for local development)
   - Click "Save"

6. **Add to Your Environment Variables:**

   **IMPORTANT:** The key MUST be prefixed with `NEXT_PUBLIC_` because Google Maps Embed API runs in the browser (client-side). This is safe because you restricted the key to only work on your specific domains in step 5.

   **Add this to your `.env.local` file:**
   ```bash
   # ============================================
   # GOOGLE MAPS API - For Bakery Demo
   # ============================================
   # Restricted to: moonlstudios.com, *.vercel.app, localhost:3000
   # Free tier: 28,000 map loads/month
   NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=your_actual_api_key_here
   ```

   **Replace `your_actual_api_key_here` with the API key you copied in step 4.**

   Example of what it should look like:
   ```bash
   NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=AIzaSyBXXXXXXXXXXXXXXXXXXXXXXXXX
   ```

7. **Use in Code:**
   ```tsx
   <iframe
     width="600"
     height="450"
     style={{ border: 0 }}
     loading="lazy"
     src={`https://www.google.com/maps/embed/v1/place?key=${process.env.NEXT_PUBLIC_GOOGLE_MAPS_API_KEY}&q=Westminster+CO+80031`}
   />
   ```

**Free Tier Limits:**
- 28,000 map loads per month (FREE)
- No credit card required for basic usage
- More than enough for demo purposes

**Cost if you exceed free tier:** $7 per 1,000 loads (but you won't reach this for demos)

## 💡 PRO TIPS

1. **Consistency:** Use the same AI generator for all images in one category (e.g., all healthcare demos from Midjourney)
2. **Mockups:** After generating, use Figma or Canva to add browser chrome or device frames
3. **Screenshots:** For "screenshot" style images, add subtle shadows and browser UI for realism
4. **Branding:** Always include the relevant color palette in your prompts
5. **Backup:** Generate 2-3 variations of each image, pick the best one
