## Implementation Notes

### Where to Add Retainer Sections on Each Service Page

Each service page should have a **"Retainer Packages"** section placed:
1. **After the main service packages section** (so users see project-based pricing first)
2. **Before the FAQ section** (natural flow: see pricing → see ongoing support → get questions answered)
3. **Before the final CTA** (gives users one more option before they contact you)

### Design Consistency

All retainer cards should use a consistent design pattern:
- **Badge/Tag:** "Retainer" label at the top
- **Title:** Clear, benefit-focused name
- **Price:** Monthly range (e.g., "$1,500–$2,500/mo")
- **What's Included:** Bulleted list of features
- **Perfect For:** One-sentence ideal client description
- **CTA Button:** "Get Started" or "Schedule Call"
